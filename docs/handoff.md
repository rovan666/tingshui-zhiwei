**当前阶段**：应付中期检查（预计 12 月初，确切日期待确认），策略为"仿真数据驱动，产出算法 demo + 硬件 BOM + 协同文档三类证据"。

**做了什么**
- 建立仓库结构与文档体系（README / handoff / agents / literature / BOM 草稿 / 启动会纪要）
- 四元均匀圆阵（UCA）信号仿真 `sim/uca_sim.py`：10 kHz 目标、SNR 0 dB、半径 3.75 cm（λ/4）、四通道带时延信号
- 常规波束形成 CBF 方位估计 `src/doa/cbf.py`：真实方位 35°，估计 35.0°，误差 0.0°
- 产出图 `figures/day1/`：四通道波形图 + CBF 方位谱（直角坐标+极坐标）
- 验证运行 `python run_demo_d1.py` 可复现出图

**关键技术决策（答辩口径）**
1. 用圆阵不用线阵：线阵有左右舷镜像模糊，无法全向监测。
2. 小孔径（r=λ/4）+ MUSIC 超分辨：低频目标要求大孔径与小船尺寸矛盾，以算法补偿孔径不足——CBF 谱峰宽、有约 -8 dB 旁瓣是预期现象，留作 MUSIC 对比图的铺垫。
3. 船载平台：监测工况采用无动力漂流监听，规避电机自噪声；该调整须指导老师确认后才写入中期报告。
4. 对外不提 AI 生成，口径为"版本管理与开发文档规范"；所有仿真图标注"仿真数据"。

**下次从哪开始（优先级排序）**
1. **MUSIC 算法**（`src/doa/music.py`）：与 CBF 同图对比方位谱，是中期答辩核心证据图。注意多途相干信号会使普通 MUSIC 失效，仿真阶段先不加多途，报告列为已知问题。
2. 能量检测器（`src/detect/`）：短时能量 + 自适应阈值（背景均值+k·σ），出检测率/虚警率曲线。
3. 规则分类（`src/classify/`）：中心频率/带宽/谱平坦度三特征区分船/人落水/鱼，出混淆矩阵。
4. 数据接口规范文档（对应申请书研究内容 1，半天工作量）。
5. BOM 逐项比价、填真实链接；首购样件（树莓派 5 + 2 只压电水听器，约 ¥850）下单。
6. Week-2：可视化（Streamlit）；Week-3：中期报告 + 12 页 PPT + 全员串讲互考 + 指导老师预审。
