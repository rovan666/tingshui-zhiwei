- 四元均匀圆阵（UCA）信号仿真 `sim/uca_sim.py`：10 kHz 目标、SNR 0 dB、半径 3.75 cm（λ/4）、四通道带时延信号

**关键技术决策（答辩口径）**

3. 船载平台：监测工况采用无动力漂流监听，规避电机自噪声；该调整须指导老师确认后才写入中期报告。
