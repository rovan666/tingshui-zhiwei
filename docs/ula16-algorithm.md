# 新方案算法说明：从 16 通道声音到连续事件

## 1. 这套代码回答什么问题

系统不是对一整段音频只给一个标签，而是持续回答四件事：

1. 现在有没有不同于背景的异常事件；
2. 如果有，声源在阵列左侧、右侧还是正前方；
3. 这个事件属于 A、B、C，还是不能可靠识别的未知类；
4. 同一个连续事件何时开始、何时结束，哪些窗属于它。

输入始终是同步的 `[16,N]` 波形。测向利用 16 通道之间的相位和幅度差，检测与分类主要使用参考通道或方向聚焦后的单通道时频图。

## 2. 为什么先做统一特征

1 秒波形有 100000 点。STFT 使用 2048 点 Hann 窗、512 点步长，右补零后得到 193 帧。log-Mel 将频率轴压缩成 128 个与人耳感知相近的频带，再取对数功率。

训练集拟合每个 Mel 带的均值和标准差，验证、测试和在线推理都冻结这份统计。若在测试集重新归一化，不仅口径不一致，还可能泄漏测试信息。

## 3. 仿真怎样避免“看起来会、实际不会”

A/B/C 母素材分别模拟脉冲、调频和调幅谐波；八类背景用于让检测器学习“正常背景长什么样”。16 通道传播采用球面波距离和分数延时，可加入三边一阶反射。

关键约束：

- 事件到达之前必须为零，不能因循环 FFT 移位提前出现尾部信号；
- 所有通道使用同一个声源增益，避免逐通道归一化破坏阵列幅度关系；
- 背景各通道独立生成，复制同一背景会形成假的正前方相干声源；
- 母素材先按 18/6/6 划分，再做混音、反射和切窗，防止同源变体跨集合。

## 4. OS-SCL 检测与事件门控

OS-SCL 用卷积骨干提取嵌入，监督对比损失让同背景伪类更集中、不同背景更分离；ArcFace 加强类间角度边界，FPH 和 Noisy-ArcMix 增加扰动训练。

在线时不直接输出八类背景，而是计算当前嵌入到最近背景原型的余弦距离。距离越大，越不像已学背景。

单个高分窗不能直接形成事件。状态机要求最近三窗至少两窗超过开启阈值；事件中间出现单个低分窗不会立刻关闭，连续三个低分窗才关闭。两秒回溯保存触发前历史，且只追加每个新窗真正新增的 250 ms，避免重叠复制。

## 5. 近场 CBF/MUSIC 与学习式频带加权

传统波束形成常把声源当成远场平面波。本方案声源距离与阵列孔径可比，因此候选网格直接包含位置 `(x,y)`，导向向量根据各阵元到候选点的真实距离计算相位和幅度。

1–6 kHz 被分为八带，每带最多选两个高于背景门限的频点。等权 CBF 是基线；MUSIC 用于单源子空间对照。

学习式测向不直接“凭空回归角度”，而是学习八个频带该信多少：

- 每个频带的 16×16 协方差变成实部、虚部绝对值、虚部符号三层图；
- 同一个两层 CNN 分别处理八个频带；
- 无效频带被掩码，softmax 只在有效频带内分配权重；
- 加权空间谱折叠到角度轴，再取峰值和近场候选点。

训练标签不是硬把真值四舍五入到一格，而是在相邻角度间线性分配概率。验证集按角度 MAE 选权重。

若没有有效频点，或主峰相对其他方向不够突出，输出“方位不确定”。因此角度误差必须与覆盖率、拒判率一起报告。

## 6. 方向聚焦与 TinySwin 分类

得到有效候选点后，对选定频点做方向引导延时求和，再经 ISTFT 还原单通道波形。这样分类器更多接收目标方向能量，而不是简单平均 16 通道导致相消。

分类分两阶段：

1. 自监督：对谱图做 30% 块遮盖，一个分支学习重建，另一个分支用 NT-Xent 学习同一事件两个增强视图的一致性；
2. 监督微调：加载同一 TinySwin 骨干，用 A/B/C 标签训练三分类头。

同一事件持续多个窗时，不是把最后一窗当最终答案，而是选检测分最高的三个窗平均类别概率。事件关闭后冻结结果。若最大概率低于验证集选出的阈值，输出“未知”。

## 7. 主入口如何防止假结果

`run_pipeline.py` 有两种明确模式：

- `baseline`：真实运行传统对照链路；
- `intelligent`：必须加载检测、测向、分类三份正式权重。

智能模式缺权重、归一化、背景门限或拒判阈值都会失败，不创建随机权重顶替，也不静默退回基线。当前尚无正式训练权重，所以不能声称智能仿真回放已完成。

## 8. 怎样验收

事件评估以连续事件为单位，而不是把所有重叠窗当成大量独立样本：

- 真值事件只匹配首个时间符合的预测；
- 同一事件后续再次触发属于额外误报；
- 纯背景单独统计误报/分钟；
- 角度同时报告 MAE、P90、覆盖率和拒判数；
- 分类报告宏 F1 和未知误接受；
- 仿真与实录分别统计。

代码测试通过只说明接口、数值约束和小规模训练步骤可运行，不等于真实海域性能达标。正式结论必须来自未参与训练和阈值选择的独立测试集。
